# 問題解決アプリ 全体モック

問題解決技法アプリの体験を、最初から最後まで通せるモックです。
「紙が埋まっていく」「泡で問いかける」「できなかったあとに戻れる」の3つが、実機で気持ちよく回るかを確かめるために作っています。

- 仕様書: [docs/mock-spec-v3.md](docs/mock-spec-v3.md)（v3 のうち「E. ふりかえり」と相談メモまで。「残す」はまだ入れていません。v2 は [docs/mock-spec-v2.md](docs/mock-spec-v2.md)）
- 画面遷移とワイヤーフレーム: [docs/wireframes.md](docs/wireframes.md)

Claude API との通信はしません。問いや要約はすべてダミーデータで動きます。

## 起動

Node.js 20 以上が必要です。

```bash
npm install
```

```bash
npm run dev
```

ブラウザで表示された URL（例: http://localhost:5173）を開きます。スマホ幅（390×844）で見るのが基準です。

パソコンなどの広い画面で開くと、スマホの大きさの窓（390px 幅）を机の真ん中に置いて見せます（中身は同じページなので、動きも紙のデータも同じです）。画面いっぱいで見たい時は、URL の末尾に `?full` を付けるか、窓の下の「この画面いっぱいで見る」を押します。

## iPhone 実機で試す

Mac と iPhone を**同じ Wi-Fi** につないでから、ネットワークに公開して起動します。

```bash
npm run dev:lan
```

ターミナルに出る `Network:` の URL（例: `http://192.168.1.23:5173`）を iPhone の Safari で開きます。

- URL が出ない・つながらない時は、Mac の IP アドレスを確認して `http://<IPアドレス>:5173` を開いてください。

  ```bash
  ipconfig getifaddr en0
  ```

- 初回に macOS のファイアウォールが「受信接続を許可するか」を聞いてきたら、許可してください。
- 共有メニューの「ホーム画面に追加」から開くと、アドレスバーなしの全画面で試せます。
- 本番ビルドで試す場合は `npm run build` のあと `npm run preview` で、同じように `Network:` の URL を開きます（ポートは 4173）。

## デモの一周（できなかった → 重なる紙）

1. 引き出しの右上の歯車（設定）→「例の紙を1枚つくる」（6番まで書いた状態の紙ができる）
2. 紙の上部の「今すぐ鳴らす」を押す → 画面上に通知「今、どう？」が出る
3. 通知をタップ → 「できなかった」→ 理由（例: 気力がなかった）を選ぶ
4. 「同じ案で、もう一度」→ 新しい紙が重なり、6番だけが明るくなる。6番を開くと「前より小さくするなら」の提案が出る

白紙から通す時は、引き出しの「新しい紙」から始めます。1番では例として次の文を入れると、仕様どおりの候補が出ます。

```
仕事がうまくいかない。月曜がつらい。会議で話せない。部屋も片付いてない。
```

## 使い方（はじめて開いた時）

はじめて開くと、机にテープで留めた「使い方」の紙が出ます（3ページ。いつでも「とばす」で閉じられ、閉じたら次からは出ません）。

| ページ | 教えること |
| --- | --- |
| 1 | 困りごとを①〜⑦の枠に1つずつ書く紙であること。見本の用紙の明るい②は、本物と同じように押せる（押すと次へ） |
| 2 | 泡の問いに答えること。本物の泡で「押す」「はじく」を1回ずつ練習でき、できた所にチェックが付く（動きを減らす設定ではカードと×） |
| 3 | ⑥で決めた時間に「今、どう？」が届くこと、できなかった日は一歩を小さくしてもう一度、引き出しとふりかえり、相談先 |

最後の「新しい紙を出す」で、そのまま白紙の紙が開きます。もう一度見る時は、設定の「使い方をもう一度見る」から開きます。

## 操作

| 操作 | 動き |
| --- | --- |
| 枠をタップ | ズームインして作業画面へ |
| 泡をタップ | 泡がキーボードに隠れない高さまで浮き上がってはじけ、はじけた所から、その問いだけが書かれたメモ用紙が出てくる |
| 書いたもののすぐ下の罫線（「ここに書く」） | 問いなしのメモ用紙が出てくる（書く入口はこの1つだけ） |
| 書いた行をタップ | 同じメモ用紙が開いて、直す・消すができる（目標・選んだ案・場面の文章も、その行から作っていればいっしょに変わる） |
| ②の場面の文章をタップ | 答えが2つ以上あれば、文章を自分で直せる |
| 上部の「今回の目標 ✎直す」 | メモ用紙で目標を直す（④の案は消えない） |
| ⑤の「④に戻って、案を足す」 | ⑤を閉じて、すぐ④が開く |
| ①の候補の下「どれでもない。自分の言葉で書く」 | 候補にない問題を、自分の言葉で書く |
| 1枚だけでまだ実行していない紙の「この紙を消す」 | 間違えて作った紙を消す（置いてある紙・やった紙は消せない） |
| 泡を指で動かす | 押してすぐ動かせる（長押しはいらない）。泡は帯の中だけを動き、ほかの泡を押しのける。ゆっくり離すと、その勢いのまま漂いに戻る |
| 泡をはじく（速く動かして離す） | 画面外へ飛ぶ。4秒だけ「元に戻す」が出る |
| 泡を長押し → そのまま離す | 泡がその場で3秒止まり、× で外せる（はじけない時の代わり） |
| メモ用紙の「追加」（またはエンター） | メモが紙飛行機に折られ、線を描きながら飛んで、リストの1行になる |
| 「書けた」 | ズームアウトして、枠に文字が入る |
| 右上の「相談先」 | 相談窓口の画面（モックではプレースホルダー） |
| 引き出しの「ふりかえり」 | E. ふりかえり（本人のためのレポート）。下の「相談メモをつくる」から相談メモへ |
| ふりかえりの日付（根拠の紙） | その紙が読むだけで開く。「この紙を開く」でその紙へ |

### 書き方の見本

メモ用紙の書く欄には、薄い印刷の字で「例：先週の月曜、朝いちばんの定例会」のような見本が出ます。打ち始めると消えます。

- 見本は問いごと（泡の問い・5番の決まった問い・6番の「どこで」「最初の2分」）と、問いのない時は枠ごとに用意しています。
- 内容に引っぱられないよう、仕事・家のこと・人づきあい・体調の4つの分野を用意し、開くたびに分野を変えます。伝えたいのは「何を書くか」ではなく「どのくらい具体的に、どのくらいの長さで書くか」です。
- 見本は、別の誰かの例です。AI が本人の困りごとに合わせて作ることはしません（答えを出さない、というこのアプリの約束のため）。
- 見本は本人のペン書き（Klee One）と見分けられるよう、刷られた字（Noto Sans JP）で出します。
- 中身は `src/lib/examples.ts` にあります。

泡は指で動かせて、はじくと外れますが、画面に書いていないので、初めて泡を見た時だけ「泡は指で動かせます。はじくと外れます」を1回出します（設定の `flingHintSeen`）。

設定では、効果音（初期オフ）と「動きを減らす」（端末に合わせる／減らす／減らさない）を切り替えられます。動きを減らすと、泡はカードになり、ズームと紙飛行機はなくなります。

## ふりかえり（E）と相談メモ

引き出しの上の「ふりかえり」から開きます。自分の過去の実績を見て、もう一度向き合うための画面です。読んで終わりにせず、**気づき → その場で一歩を小さくしてもう一度**を1タップでつなぎます。持ち上げも励ましもせず、記録を映し返すだけにしています。

画面は上から：

1. 見出しと期間
2. **戻ってきた回数**（大きく）と、書いた紙（小さく）。「踏み出した一歩」は出しません（書いた紙と並ぶと、割り算されて「半分しかできてない」に見えるため）。戻ってきた回数が0の時は、書いた紙だけ
3. **まとめの一文**（1〜2文。例：「あなたの場合、最初の一歩を5分以内にすると動けています。止まった2回も、一歩を縮めて戻ったら動けました。」）。「根拠を見る」を押すと、うまくいった時の条件と効いた変え方が、根拠の紙の日付つきで開きます
4. **もう一度やってみる？**：「今回は見送り」のまま止まっている紙を、新しい順に2枚まで。前回の最初の一歩と、まとめから作った縮小版の提案（例：「5分以内の一歩にして、もう一度やってみる？」）を出します。「この紙で、もう一度」で、紙が重なり、6番が開いて、最初の一歩に提案が下書きで入ります。「今はいい」はカードを閉じるだけで、何も記録しません。見送りの紙がなければ、この欄は出ません
5. 書き方の変化（中身がある時だけ。たたみ表示）
6. 注記、相談メモをつくる

- **最初から入っている過去の紙（6枚）**: 仕様のデモ用の紙を、日付を今日から数えて入れています。前から使っている端末にも1回だけ入ります。消した時や試したあとは、設定の「ふりかえり用の過去の紙（6枚）を入れなおす」で戻せます。
- **数えるのはプログラム**（`src/lib/records.ts`）: 書いた紙の枚数、戻ってきた回数、一歩の大きさごとの数、まだ戻っていない見送りの紙（`stoppedPapers`）。Claude の役の関数は、この数を言葉にするだけです。
- **Claude の役（ダミー）**（`src/claude/index.ts`）: `analyzeRecords`（まとめの一文・うまくいった条件・効いた変え方・書き方の変化。各行に根拠の紙を必ず付け、根拠が2枚未満の項目は null）、`shrinkPlan(plan, { summary, minutes })`（まとめで見つかった条件で一歩を縮める。デモの一歩は `dummyData.ts` の `SHRINK_STEPS`）、`buildConsultMemo`（相談メモの下書き）、`filterOutput`（禁止語を含む文を落とす）。禁止語は `dummyData.ts` の `BANNED_WORDS`。
- **空の項目は出さない**: null の項目は画面に出しません。全部 null の時（紙が3枚未満など）は、まとめの一文の代わりに「まだ紙が少ないので、傾向は書けません。書いた紙：○枚」だけを出します。
- **見た目の分け方**: 数と本人の言葉（ペンの字）は事実、緑がかった帯の中（「記録から見えた傾向（参考）」）は Claude が読みとった傾向です。縮小版の提案は本人の言葉ではないので、ペンの字にしません。
- **根拠の紙**: たたみの中の各行に、日付を新しい順に4つまで添えます（それより多い時は「ほか○枚」）。押すとその紙が読むだけで開きます。
- **今どう？の「あなたの記録」**: 「できなかった」を押すと、理由を選ぶ前に、まとめの一文と、今の紙への縮小版の提案を1つ出します。「これで、もう一度」→ 理由を1つ選ぶ（「とばす」もできる）→ 紙が重なり、6番が開いて、提案が下書きで入ります。「別の方法を考える」「今は置いておく」も、理由のあとにそのまま進みます。「今は見ない」は、これまでどおり理由 → 3択です。

相談メモは、ふりかえりの下の「相談メモをつくる」から作ります。

1. 期間（すべて／直近3か月／直近1か月）と、入れる紙を1〜3件選ぶ。紙は初めは何も選ばれていません
2. 下書きを全文確認する。色のついたところは押すと書き換えられます。「今日話したいこと」は本人が書きます
3. 「この内容で確定」→「印刷する（PDF）」か「画面で見せる」。どこにも自動で送りません

本人用の「記録に基づく一言」と「次に試せること」は、相談メモには入れていません。印刷では、確定したメモだけを A4 一枚に刷ります（`src/index.css` の `@media print`）。

## 紙の見た目と動き

紙は記入用紙として作っています。印刷された部分（枠・見出し・罫線）は緑の特色1色、本人が書いた部分はブルーブラックのペン（Klee One）です。この「印刷」と「ペン」の区別は、作業画面・引き出し・今どう？画面でも同じにしています。

引き出しは、机の上に紙が並んでいる、というところだけを残して、飾りの凹凸（真鍮の札・光るボタン・へこんだ箱・浮き彫りの線）は持たせていません。机は木目をうすく洗った面（`.desk-calm`。紙・ふりかえり・相談メモ・今どう？も同じ机で、上に貼りつく見出しの帯も同じ色の無地）、見出しは大きな「引き出し」の文字だけで、スクロールすると上の帯に小さく残ります。書いている途中の紙には、用紙に刷られた番号 ①〜⑥ を並べ、書けた枠をペンの色で示します（読み上げは「③まで書いた」）。点線のふちは「押せない」の印なので、「新しい紙」は実線の白い紙の束にしています。

泡の中の問いは、言葉の途中（「範／囲」）では折り返さず、文節の切れ目（「今週できる／範囲だと？」）で折り返します。文節は Google の [BudouX](https://github.com/google/budoux)（Apache-2.0）で分け、泡の大きさは、いちばん長い文節が1行に入る大きさ以上にしています（帯が低くて泡を大きくできない時だけ、字を少し小さくします）。使い方の説明と引き出しの紙の題名も、同じように文節で折り返します。一度に浮かべる泡の数は、帯の広さと文字の大きさから決めます（2〜4個。文字を大きくした小さい画面では減らし、残りの問いは泡が減ったら順に出てきます）。

泡は、写真のようなシャボン玉ではなく、紙の世界になじむ挿し絵くらいの描きこみにしています（印刷と同じ緑の輪郭線、縁の内側で緑と真鍮の金のあいだだけを行き来する膜の色、やわらかい光の窓と金の照り返し、平らな影）。泡の中の問いは、用紙に刷られた言葉なので印刷の緑で、縁取りは紙の色です。はじけた時のかけらやしずくも、このアプリの色（緑・ブルーブラック・真鍮の金）だけを使います。

泡どうしのぶつかりは、2D の物理エンジン [matter.js](https://brm.io/matter-js/) で計算し、描くのは three.js（React Three Fiber）です。当たり判定は見た目より少し小さく（半径の 92%）、触れ合った泡は見た目が少し重なります。その重なりをシェーダーで平らにつぶし、2つの泡のあいだに1本の膜の壁を描くので、シャボン玉が押し合っているように見えます（大きい泡の方が多くつぶれる）。壁は2つの泡が同じ平面を使って片側ずつ描き、合わせると輪郭線より少しだけ太い1本になります。壁の両端の角は丸めません（丸めると両端が内側へ引っこみ、泡と泡のあいだに切れこみができるため）。ぶつかった泡は当たった向きにぷにっとつぶれて何度かゆれ、漂っている泡は相手から離れる向きへ進み直します。指で持っている泡は重くなってほかの泡を押しのけ、飛ばした泡は途中の泡をはじき飛ばします。止めた泡（長押しして離した泡）には、ほかの泡がぶつかってはね返ります。物理エンジンは 3D の部品といっしょに後から読み込むので、最初に開く時の重さは変わりません。

### 画面の切り替え

切り替えの物差しは [transitions.dev](https://transitions.dev/) の motion tokens にそろえ、[src/lib/motion.ts](src/lib/motion.ts) にまとめています。入る・開くは少しゆっくり（250ms）、出る・閉じるは速く（150ms）。動く距離は 8px ほどと短く、そのぶん 2〜3px のぼかしを重ねて「入れ替わった」と分かるようにしています。カーブは1本（`cubic-bezier(0.22, 1, 0.36, 1)`）で、弾ませるのは数字だけです。

| 切り替え | 動き | 場所 |
| --- | --- | --- |
| ふりかえり・相談メモ・相談先を開く | 右から少しずれて、ぼかしを解きながら入る。下のページは左へ少し下がってぼける | `pageScreen`、`recede` |
| 相談メモ・今どう？の段階 | 進むと右から、戻ると左から入る。今どう？のメモは高さも伸び縮みする | `StepSwap`（`step`）、`ResizeBox` |
| 設定 | 下から短くせり上がる | `sheet` |
| 読むだけの紙・画面で見せる | 真ん中で、少し小さいところから開く | `modal` |
| 通知 | 上から入る | `toast` |
| 根拠を見る・書き方の変化 | 高さで開き、中身のぼかしが解ける。矢印は上下に裏返る | `.fold`、`.flip`（`src/index.css`） |
| ふりかえりの数字 | 1けたずつ、下から少し行き過ぎて止まる | `PopNumber` |
| 「消す」→「本当に消す」・置いてある紙の帯 | その場で言葉が入れ替わる／高さを伸ばしながら開く | `Swap`、`StepSwap`（`swap`） |
| 枠を開く（作業画面） | 押した枠から広がり、閉じる時は速くそこへ戻る | `src/screens/WorkScreen.tsx` |

紙・クリップボード・紙飛行機・泡の演出はこのアプリの見せ場なので、この物差しには寄せず、それぞれの動きのままにしています。

引き出しから紙を開く時は、紙が用意されていく順に見せます（全体で2秒ほど。動いている間も枠は押せます）。

| 開く紙 | 動き |
| --- | --- |
| 新しい紙 | 束のいちばん上の1枚がはがれて持ち上がる → 引き出しが消えていく上に、まっさらな紙を載せたバインダーが机の手前から置かれる → クリップが手前へ持ち上がって口が開き（紙に影が落ちる）、紙が下から口へ差しこまれる → クリップが「カチ」と閉じ、バインダーがほんの少し沈む → 用紙の外枠が引かれ、上の段から順に刷られる → 記入日が書きこまれる → ①の「ここから」がそっと光る |
| 書きかけ・書き終えた紙 | 押した紙が少し持ち上がる → 紙を載せたバインダーが置かれ、クリップが開いて紙が差しこまれ、「カチ」と閉じる → 次に書く枠がそっと光る |

紙は、はじめからバインダーに載せて出します（何も載っていない板を見せると、一瞬画面いっぱいに茶色が広がって目に強いため）。クリップの音は、紙を重ねる時の「カチッ」（揺れつき）より軽い「カチ」で、揺らしません（開くたびに鳴るため）。動きを減らす設定では、すぐに開きます。

## 設定

| 項目 | 内容 |
| --- | --- |
| 効果音・音量 | 初期はオフ。音はすべて効果音バス → マスター（音量・リミッター）を通り、同じ音も毎回少しずつ高さが変わる |
| 動きを減らす | 端末に合わせる／減らす／減らさない |
| 画面の揺れ | なし／少し／ふつう（泡がはじけた時・紙をはさんだ時の小さな揺れ） |
| 文字の大きさ | ふつう／大きめ／もっと大きく（文字・余白・罫線・泡がいっしょに大きくなる） |
| 泡を止めるまでの長押し | 短め／ふつう／長め（長押しして離すと、泡が止まって × が出る） |
| 使い方をもう一度見る | はじめて開いた時の「使い方」をもう一度出す |
| フレームレートを表示（デバッグ） | 実機で泡やズームがカクつくかを数字で見る（目標 60fps） |

Esc キーでいちばん上の画面が閉じます（相談先 → 設定 → 下の紙 → 今どう？ → 作業 → 紙 の順）。

## 手ごたえの強さ

出来事ごとの音・振動・揺れ・粒の組み合わせは [src/lib/juice.ts](src/lib/juice.ts) にまとめてあります。強さは3段階です。

| 強さ | 出来事 |
| --- | --- |
| small（音か振動だけ） | 泡を飛ばす、泡どうしが強めにぶつかる（音だけ）、紙飛行機が飛び立つ、引き出しから出した紙をはさむ、通知が届く |
| medium（粒＋音＋振動＋ごく小さな揺れ） | 泡がはじける（ヒットストップつき）、紙飛行機が着地する、やった（揺れなし） |
| large（はっきりした揺れ） | 枠が埋まる、新しい紙をはさむ |

## 仕様の読み方で決めたこと

- **2番「問いは1枠につき最大2回まで」**: 泡の補充を2回までと読みました（最初の4個＋補充2回で、7つの問いを出し切れる）。
- **泡の数**: 3番・6番は仕様の問いがそれぞれ3個・2個なので、漂う泡もその数までです。
- **3番の目標**: 書いた行から1つ選ぶ形にしました（初期は最後に書いた行）。泡の問いへの答えと、目標そのものを分けるためです。
- **6番**: いつ・どこで・最初の2分の3つが埋まると「書けた」が押せます。
- **重なった紙の6番**: 前の計画が入った状態で開きます（変えたい一点だけ変えられるように）。
- **「今は考えたくない」のあと**: 引き出しに戻ります。紙を開くと「また聞いて」「今どう？」から再開できます。
- **置いてある紙**: 開くと「もう一度やる」→「同じ案で／別の案で」を選べます。
- **「ここから」の光**: やってみた結果（⑦）まで書いた紙では、空いている枠が残っていても光らせません。
- **ふりかえり用の過去の紙**: ②の場面の一文と、選ばなかった案も入れています（開いた時に空欄だらけに見えないように）。前から使っている端末では、設定の「ふりかえり用の過去の紙（6枚）を入れなおす」で入れ替わります。
- **作業画面の上の欄**: 画面の高さが文字の大きさに比べて低い時（高さ÷文字の倍率が 620px 未満）は、「困りごと」「目標」などを1行ずつにたたみます。押すと全文が出ます（目標は、押すと直すメモ用紙が開きます）。
- **相談窓口の情報**: モックではプレースホルダーです。本番では公的機関が公開している窓口一覧から取得します。
- **ふりかえりの数（デモの6枚）**: プログラムで数えると、踏み出した一歩は4回です（仕様のダミーでは5回。実行は1枚目の2枚目・3・4・5の4つ）。「5分以内の一歩」も、1枚目の1枚目（廊下でメモ・2分）が見送りなので「5枚のうち4枚が動いた」になります。数はプログラムが数える、という仕様に合わせて、実際に数えた数を出しています。
- **戻ってきた回数**: 「今回は見送り」で止まったあと、その紙に新しい紙を重ねた、または同じ困りごとを新しい紙に書いた時に数えます。1回止まるごとに、数えるのは1回までです（デモの6枚では2回）。
- **一歩の大きさ**: 紙に時間が入っていればそれを、なければ「最初の2分」に書いた文の「30秒」「5分」を読み、それもなければ2分とします。
- **相談メモの期間**: 初めは「すべて」です。紙は何も選ばれていない状態から始まります。
- **置いてある紙の「もう一度やる」**: 紙の頭の帯に置き、ふりかえり・今どう？と同じく縮小版の提案つきです。「同じ案で、もう一度」で⑥が、「別の案で」で⑤が、そのまま開きます。
- **引き出しの並び**: 最近さわった順（`updatedAt`）です。カードには「③まで書いた」「11月5日(木) 8:50 に聞く」の一言を添え、困りごとをまだ選んでいない紙は少し沈ませています。
- **流れの切れ目**: 実行待ちの紙は「あとは当日。◯時に聞きます」の帯を見出しといっしょに上に貼りつけているので、⑥を書き終えても紙の頭へは戻しません（下へ送ってすぐ上へ戻すと、スクロールが逆に動いたように見えるため）。「やった」のあとは⑦が見える位置まで送ってからチェックが入ります。紙を重ねた時は頭から見せます。
- **今どう？のメモの位置**: 上端を固定しています。まん中寄せだと、段階が変わって高さが変わるたびにメモの頭が上下に動くためです。「これで、もう一度」のあとの理由を選ぶ段階でも、選んだ一歩を上に出したままにします。
- **書き直す時に見比べるもの**: メモ用紙は下の画面を隠すので、⑥の「どこで」「最初の2分」を書く・直す時は、前回の紙の一歩（場所）と小さくした案を用紙の中に出し、押すとその言葉が入ります。1つだけ入る欄のボタンは「追加」ではなく「書く」（もう書いてあれば「直す」）です。
- **縮めた一歩の言い方**: 縮めた一歩でも止まった時は、もう一段小さい一歩をダミーの言い換え表（`SHRINK_STEPS`）から出します。表に無い時は「『元の一歩』の、最初のひと手だけ」と、元の一歩を『』でくくります。
- **「もう一度やってみる？」に出す紙**: いちばん上の紙が「今回は見送り」で、まだ戻っていない紙です（その紙に紙を重ねた・同じ困りごとを新しい紙に書いた時は、もう戻っているので出しません）。
- **重ねた紙の「いつ」**: 前の計画の日時が過ぎていれば、明日の朝 8:50 にします（過ぎた日時のまま始まらないように）。どこで・最初の2分は前の紙から引き継ぎ、縮小版の提案を選んだ時は最初の2分に提案が入ります。
