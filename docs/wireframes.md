# 画面遷移とワイヤーフレーム

仕様書: [mock-spec-v2.md](mock-spec-v2.md)

## 遷移図

```
                 ┌──────────────────────── 相談先（全画面の右上から / 深刻判定で強制）
                 │
 [A 引き出し] ──新しい紙/カード──▶ [B 紙] ──枠タップ(ズームイン)──▶ [C 作業]
      ▲                              ▲  ◀──書けた(ズームアウト+文字が入る)──┘
      │                              │
      │                    6番を書く → 実行待ち（「◯日◯時に聞きます」＋今すぐ鳴らす）
      │                              │
      │                     通知「今、どう？」をタップ
      │                              ▼
      │                         [D 今どう？]
      │        ┌──────────┬──────────┼───────────────┬──────────────┐
      │      やった       まだ      できなかった       今は考えたくない
      │   7番「できた」  次の時間   理由を選ぶ          通知停止
      │   紙が少し明るく  を選ぶ        │              「また聞いてほしくなったら…」
      │     → B         → B    ┌──────┼────────┐        → A
      │                      同じ案で 別の案で  今は置いておく
      │                     新しい紙が重なる    紙をしまう演出
      │                     6番だけ明るい       → A の下段
      │                     (別の案: 5,6番)
      │                        → B
      └──────────────────────────────────────── 置いておく
```

## A. 引き出し

```
┌──────────────────────────────┐
│ 引き出し              [相談先]│
│ 紙 4枚                        │
│ ┌──────────────────────────┐ │
│ │＋ 新しい紙                │ │
│ └──────────────────────────┘ │
│ ┌──────────────────────────┐┐│  ← 2枚目以降は下に紙が覗く
│ │会議で話せない        2枚目││││
│ │● 実行待ち                ││││
│ └──────────────────────────┘┘│
│ ┌──────────────────────────┐ │
│ │月曜がつらい               │ │
│ │✎ 書いている途中           │ │
│ └──────────────────────────┘ │
│ ─ 置いてある ─────────────── │
│ ┌──────────────────────────┐ │  ← 少し薄く
│ │部屋が片付いていない        │ │
│ │◌ 置いてある               │ │
│ └──────────────────────────┘ │
│ 誰かに相談するのも、ひとつの選択です │ ← 置いてある紙が3枚以上の時だけ
│                       [設定] │
└──────────────────────────────┘
```

## B. 紙

```
┌──────────────────────────────┐
│ ‹ 引き出し            [相談先]│
│ ┌ 月10日 8:50 に聞きます ─────┐│ ← 実行待ちの時だけ
│ │              [今すぐ鳴らす]││
│ └─────────────────────────────┘│
│ ┌────────────────────────── ┐┐│ ← 紙（クリーム色）。下の紙が端から覗く
│ │                   2枚目    ││ │
│ │ 1 いま困っていること       ││ │
│ │   会議で話せない           ││ │
│ │ 2 どんな場面か             ││ │
│ │   月曜9時の会議室で…       ││ │
│ │ 3 今回の目標               ││ │
│ │ 4 できそうなこと           ││ │
│ │ 5 やってみること           ││ │
│ │ 6 いつ・どこで・最初の2分  ││ │ ← 次に書く枠だけ、ほんの少し明るい
│ │ 7 やってみてどうだった     ││ │ ← タップ不可
│ └────────────────────────── ┘┘│
└──────────────────────────────┘
```

## C. 作業（例: 4番）

```
┌──────────────────────────────┐
│ ‹ 紙へ    できそうなこと [相談先]│
│ いま困っていること: 会議で話せない│ 上部: 必要な情報だけ
│ 今回の目標: 要点を1つ言う ✎    │ ← タップでその場で直せる
├──────────────────────────────┤
│ 3個                           │ 中部: これまでの入力
│ ・資料に要点を1行書いておく     │ （ここだけスクロール）
│ ・同僚に先に話しておく          │ ← 球が着地して短く光る
│ ・最初の一言を決めておく        │
├──────────────────────────────┤
│   ◯人に頼む      ◯5分で       │ 下部: 泡（3〜4個が漂う）
│        ◯場所を変える          │   タップ→問いが見出しに
│                               │   長押し+スワイプ→飛ばす
│ 人に頼むとしたら？             │ ← 選んだ問い
│ [ 入力欄                ][追加]│
│ [          書けた            ] │
└──────────────────────────────┘
```

枠ごとの違い:

| 枠 | 上部 | 中部 | 下部 |
| --- | --- | --- | --- |
| 1 | なし | 吐き出したもの（薄く「整理せずそのまま」） | 泡なし。複数行入力。書けた → 問題候補2〜3個から1つ選ぶ |
| 2 | 困っていること | 場面の文章（答えるたびに書き換わる）＋答え | 映像にする問い。「目標を思いついた」 |
| 3 | 困っていること・場面 | 書いた行（タップで目標に選ぶ。初期は最新） | 目標の問い。書けた |
| 4 | 困っていること・目標(編集可) | 案（件数だけ） | 角度を変える問い。書けた |
| 5 | 困っていること・目標(編集可) | 4番の案から1つ選ぶ → 固定の問い2つ | 泡なし。書けた |
| 6 | 困っていること・目標(編集可) | いつ／どこで／最初の2分（＋縮小版の提案） | 計画の問い。書けた → 実行待ち |

## D. 今どう？

```
┌──────────────────────────────┐
│                       [相談先]│
│ 今、どう？                    │
│ ┌──────────────────────────┐ │
│ │いつ   月曜 8:50           │ │ ← 6番の内容
│ │どこで 会議室に入る前の廊下 │ │
│ │最初の2分 メモに要点を1つ   │ │
│ └──────────────────────────┘ │
│ [ やった                    ] │
│ [ まだ（あとで聞いて）       ] │
│ [ できなかった              ] │
│ [ 今は考えたくない          ] │
└──────────────────────────────┘
 できなかった → [理由 3〜4個 ＋ その他（書く）] → [同じ案で／別の案で／今は置いておく]
```
